# Tasa de pases a 1 dia

Carpeta de trabajo para incorporar al filtro BCRA la serie oficial 150.

- Titulo visible: `Tasa de pases a 1 dia`.
- Descripcion oficial: tasa de interes por operaciones de pases entre terceros a 1 dia.
- Frecuencia: diaria.
- Unidad: porcentaje nominal anual.
- Cobertura inicial verificada: desde el 2 de enero de 2008.
- Fuente: API de Estadisticas Monetarias del BCRA.
